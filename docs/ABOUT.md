# Elite для Вектора-06Ц — описание версии

Состояние на 17.10.2026 (коммит e9ed937). Источники сравнения — `docs/research/differences.md` (разбор кода BBC
и снимка памяти ZX 48K), журнал `docs/JOURNAL.md`, код и тесты репозитория. Где о ZX 48K сведений нет — так и
сказано.

## 1. Что это

Elite (Acornsoft, 1984) для ванильного Вектора-06Ц: i8080 3 МГц, 48 КБ, две плоскости экрана, звук ВИ53, без
квазидиска и без AY. Основа — кассетная версия для BBC Micro, перенесённая на i8080 и сверенная с настоящим кодом
BBC (образ стенда совпадает с BBC на семи сценариях игры). Сверху — добавки дисковой BBC, правила и миссии
версии для ZX Spectrum 48K, тексты Elite Legend (ZX 128) и своё.

| образ | что это |
|---|---|
| `elite.rom` | основная сборка, английский текст |
| `elite_ru.rom` | русская сборка (`sh v06c/build.sh -DRUS`): весь текст по-русски, прописными; названия планет латиницей |
| `elite_merid.rom` | планета с меридианами и кратером, как на BBC; без мелодии (не хватает места) |
| `elite_t.rom` | образ стенда — кассетная BBC как есть, для сверки |

Запуск: на MiSTer — `games/VECTOR06/Elite.rom` (и другие образы); в Emu80 —
`Emu80qt --platform vector --run elite_ru.rom`; в эмуляторе vector06js — `?elite.rom`.

## 2. Что есть в игре

- **Полёт и бой.** Обзор 256×192, четыре вида (вперёд, назад, влево, вправо), сканер, панель приборов в четыре
  цвета. Солнце, луч лазера и облака взрывов красные; при попадании по нам экран вздрагивает, вспышка бомбы
  желтит экран.
- **31 тип объектов:** все корабли дисковой BBC (Sidewinder, Mamba, Krait, Adder, Gecko, Cobra Mk I и Mk III, Worm,
  Python, Boa, Anaconda, Asp Mk II, Fer-de-Lance, Viper, Constrictor, Shuttle, Transporter, таргоиды и таргоны),
  станции Coriolis и Dodo (в системах с техникой от 10), астероиды, валуны, обломки, контейнеры, каменный
  отшельник.
- **Поведение кораблей** — как на диске BBC: торговцы летят к станции и стыкуются, мирные — к планете, охотники
  за наградой нападают на беглеца, станция выпускает полицию, челноки и торговцев, Anaconda — Worm.
- **Лазеры:** импульсный, лучевой, военный, добывающий (обломки астероидов — минералы). Ракеты, ECM,
  энергетическая бомба, спасательная капсула, топливозаборник, блок энергии, галактический привод.
- **Автопилот стыковки** (стыковочный компьютер) — ведёт корабль в док сам, его можно отключить.
- **Ангар** при стыковке, **прыжок к планете** внутри системы, гиперпрыжок, галактический прыжок.
- **Рынок:** 17 товаров; покупка и продажа числом, «всё» или «ничего».
- **Карты:** галактическая и ближняя, быстрый курсор, поиск системы по названию.
- **Расширенные описания планет** (дисковая BBC) и 25 особых — подсказки к миссиям.
- **Пять миссий:** три версии ZX («Сверхновая», «Скрывающее устройство», «Захват станции») и две дисковой BBC
  («Констриктор», «Планы таргоидов»).
- **Счёт и ранги** — очки, как в ZX 48K; правовой статус.
- **Сохранение командира на магнитофон** (77 байт, ≈6 с), загрузка с ленты.
- **Звук** на ВИ53 в три голоса: лазер, взрывы, ракеты, гудки, ECM.
- **Заставка загрузчика BBC** — Сатурн из точек, надписи «ВЕКТОР 06Ц» и ELITE в перспективе.
- **Мелодия на заставке** — главная тема вальса «На прекрасном голубом Дунае» в три голоса (из записи Elite для
  Commodore 64), ≈41 с по кругу.
- **Цвета:** бордовый, тёмно-зелёный, светло-бежевый; заголовки и подписи зелёные, значения бежевые.
- **Управление в полёте под русскую клавиатуру Вектора** (стрелки, Я/ТАБ, буквы по смыслу), джойстик «П».

## 3. По сравнению с ZX Spectrum 48K

### Что лучше или больше

| | Вектор | ZX 48K |
|---|---|---|
| обзор | 256×192 | 256×128 |
| цвет в обзоре | бежевый + красный (солнце, лазер, взрывы), текст зелёный | одноцветный (атрибут на окно) |
| панель | 4 цвета, 256×56 | атрибуты |
| мерцание | приглушено порядком печати | нет (буфер), но перенос буфера стоит почти кадр |
| типов объектов | 31 | 19 |
| станция Dodo, Shuttle, Transporter, Boa, Anaconda, Worm, Gecko, Adder, Cobra Mk I, Mamba, валун | есть | нет |
| поведение по типу корабля (торговцы стыкуются, мирные летят к планете) | как дисковая BBC | не разобрано |
| охотники за наградой | нападают при статусе «беглец» | из-за ошибки в коде ZX — почти всегда |
| стыковочный компьютер | автопилот, ведёт корабль в док | мгновенная стыковка с показом |
| ангар при стыковке | есть | не разобрано |
| продажа | «да», «нет» или число | не разобрано |
| миссии | 3 из ZX + 2 из дисковой BBC | 3 |
| особые описания систем (подсказки) | 25 | нет |
| звук | ВИ53, три голоса | бипер |
| музыка | «Голубой Дунай» на заставке | нет |
| джойстик | «Джойстик П» и джойстик MiSTer | Kempston |
| язык | английский или русский | английский |
| сохранение | при неудаче — прежний командир и снова вопрос | командир из копии |

### Что взято из ZX 48K

Счёт очками и границы рангов; правила появления кораблей (дерево ZX, контрабанда учащает появление, полиция —
часть мирного движения, таргоиды — 1 из 64 одиночек); урон по грузу (10 из 64 ударов) и утечка топлива
(1 из 64); галактический прыжок обнуляет правовой статус; три миссии ZX со скрывающим устройством и глушилкой
ECM; каменный отшельник.

### Чего у Вектора нет, а в ZX 48K есть

- Выбор управления на заставке (у нас джойстик определяется сам).
- Подбор контрабанды не портит правовой статус (в ZX — портит).
- Приборы от попаданий не гибнут (в ZX — 6 из 64 ударов; решение владельца — только груз).

### Скорость

Замер 17.10.2026 в настоящем времени (кадры 50 Гц), одинаковый путь в обеих версиях: заставка с вращающимся
кораблём, затем вылет с Лейва без нажатий. Вектор — `node tools/analysis/speed_zx.mjs` (проходы главного цикла по
MCNT), ZX 48K — снимок игры в стенде `tools/analysis/zx48_run.mjs "300 60:_ 200 30:1 400 500 3000"` (проходы — по
переносу буфера обзора на экран, раз за проход).

| проходов в секунду | Вектор | ZX 48K | во сколько раз |
|---|---|---|---|
| заставка | 8,2 | 6,7 | 1,2 |
| полёт: 10 с после тоннеля | 21,7 | 9,9 | 2,2 |
| полёт: следующие 60 с | 18,9 | 10,2 | 1,8 |

Оговорки. Корабли появляются случайно, сцены в обеих версиях не одинаковы. Ядро Z80 в стенде ZX не замедляет
обращения к нижним 16 КБ памяти (у настоящего Spectrum они медленнее), так что ZX здесь скорее быстрее, чем на
деле. Обзор у Вектора больше: 256×192 против 256×128. Русская сборка идёт с той же скоростью (18,9).

## 4. Управление

Клавиши — по надписям на клавиатуре Вектора. Буквы в доке и на картах — латинские надписи клавиш (у Вектора на
одной клавише русская и латинская буква, например Д и D); в полёте — по русским надписям.

### Заставки

| клавиша | что делает |
|---|---|
| любая | с заставки с Сатурном — дальше |
| Д / Н (английская: Y / N) | загрузить командира с ленты или начать новую игру |
| пробел или огонь | начать игру (вторая заставка) |

### Док (на станции)

| клавиша | экран |
|---|---|
| F1 | вылет |
| F2 | купить товар |
| F3 | продать товар |
| F4 | оснащение корабля |
| F5 | галактическая карта |
| СС + F1 | ближняя карта |
| СС + F2 | данные о выбранной системе |
| СС + F3 | цены рынка |
| СС + F4 | статус командира |
| СС + F5 | трюм |
| Ю (@) | записать командира на ленту |

**Покупка (F2).** Товары предлагаются по одному: ввести число и ВК; Д (Y) — сколько поместится и хватит денег,
Н (N) — пропустить. **Продажа (F3):** по каждому товару в трюме — Д/Н (Y/N) или число.

**Оснащение (F4).** Ввести номер предмета и ВК. Для лазера — затем цифра стороны: 0 — передний, 1 — задний,
2 — левый, 3 — правый.

**Запись на ленту (Ю).** Ввести имя и ВК, включить запись на магнитофоне и нажать любую клавишу. **Загрузка** — на
заставке Д (Y), имя и ВК, пустить ленту; пробел или СС — отмена.

### Карты (галактическая F5, ближняя СС + F1)

| клавиша | что делает |
|---|---|
| стрелки | двигать крестик |
| СС + стрелки | вчетверо быстрее |
| D (Д) | выбрать систему у крестика: название и расстояние внизу |
| O (О) | крестик — на текущую систему |
| F (Ф) | поиск по названию: набрать латиницей и ВК |
| СС + F2 | данные о выбранной системе |
| H (Х) | гиперпрыжок к выбранной системе (если в полёте) |

### Полёт

| действие | клавиша |
|---|---|
| крен влево / вправо | ← → |
| нос вниз / вверх | ↑ ↓ |
| огонь (лазер) | пробел |
| разгон / тормоз | Я / ТАБ |
| ракета: навести / пустить / снять | Ц / Р / С |
| ECM (РЭБ) | Е |
| энергетическая бомба | Б |
| спасательная капсула | К |
| автопилот стыковки: включить / отключить | А / О |
| прыжок к планете | П |
| гиперпрыжок / галактический | Г / УС + Г |
| маскировка (после миссии) | М |
| вид вперёд, назад, влево, вправо | F1, F2, F3, F4 |
| карты, данные, статус, цены, трюм | F5, СС + F1…F5 — как в доке |
| пауза | СТР |

Гиперпрыжок: выбрать систему на карте (крестик и D), выйти на вид из корабля и нажать Г — пойдёт отсчёт.
Расстояние — не больше запаса топлива (7,0 светового года при полном баке). Галактический прыжок — с
галактическим приводом.

### Пауза (СТР)

На паузе — клавиши BBC:

| клавиша | что делает |
|---|---|
| ЗБ | продолжить |
| АР2 | начать заново |
| Q (Я) / S (С) | звук выключить / включить |
| A (А) | возврат рулей к середине |
| X (Ь) | имена авторов на заставке |
| F (Ф) | мигание приборов |
| Y (Ы) | обратный тангаж джойстика |
| J (Й) | обратные оси джойстика |
| K (К) | джойстик или клавиатура |

### Миссии

Вопросы миссий — Д/Н (английская сборка: Y/N). Текст миссии на экране листается любой клавишей.

### Джойстик («Джойстик П», джойстик MiSTer)

| | в полёте | на экранах |
|---|---|---|
| влево / вправо | крен | стрелки |
| вверх / вниз | нос вниз / вверх | стрелки |
| огонь | лазер | пробел |
| вторая кнопка | разгон | ВК |
