# Elite для ZX Spectrum 48K (Firebird, 1985): разбор снимка памяти

Составлено 08.10.2026. Источник — снимок `.z80` владельца (в репозиторий не входит; рабочая копия —
`work/zx48/elite48.z80`, память 4000h–FFFFh — `work/zx48/zxram.bin`). Тексты и модели разобраны раньше —
`zx48_texts.md`. Здесь — устройство программы, переменные, корабли, миссии.

Инструменты (в репозитории):

- `tools/analysis/zx48_trace.py` — обход кода по переходам от точек входа (`zx48_seeds.txt`), делит память на код и
  данные, пишет `work/zx48/map.txt`, `calls.txt`, блок-файл для `z80dasm`;
- `tools/analysis/zx48_guess.py` — подбирает точки входа для кусков, до которых обход не дошёл (косвенные вызовы);
- листинг: `z80dasm -a -l -t -g 0x4000 -b blocks.txt -o elite48.asm zxram.bin` в `work/zx48` (39 тыс. строк).

**Степень разбора.** Память размечена целиком, но по процедурам прочитана только часть: печать текста, экран статуса,
выдача и ход трёх миссий, появление кораблей, таблица типов, галактический прыжок, урон и утечка топлива,
стыковочный компьютер. Движок (математика, печать отрезков, тактика, рынок, карты) по процедурам не разбирался.
Деление на код и данные — эвристика: 303 точки входа, из них часть подобрана по частоте адреса в командах `CALL`
и по правдоподобию цепочки команд; границы могут быть неточны на десятки байт.

### Обзор рисуется в буфер

Адрес точки берётся подпрограммой ПЗУ `PIXEL-ADD` (`22B0h`, шесть вызовов из `89D4h`, `89EFh`, `8A37h`, `8A82h` и
рядом), и сразу за вызовом стоит `SET 7,H`: адрес экрана `4000h–4FFFh` превращается в `C000h–CFFFh`. То есть
обзор — 256×128 точек, рисуется вне экрана и переносится на экран целиком; мерцания стирания нет. Процедура
переноса буфера на экран не найдена.

### Обращения к ПЗУ и к портам

`03B5h` (BEEPER — звук), `04C6h` и `0562h` (запись и чтение блока с ленты), `22AAh/22B0h/22B1h` (адрес точки).
Порты: `OUT (FEh)` — 8 мест (бордюр и динамик), `IN A,(C)` — клавиатура. Прерывания в снимке запрещены.

## Объекты и типы кораблей

Блок объекта — 39 байт (`IX+0…IX+38`): `IX+22h` — «место занято», `IX+23h/24h` — адрес заголовка модели,
`IX+25h`, `IX+26h` — флаги (бит 0 `IX+25h` — враждебен, бит 2 `IX+26h` — станция). Мест восемь; процедура поиска
свободного места `B936h` просматривает шесть (места 1–6), место 0 и место 7 (`6159h`) — особые. Значит, обычных

### Появление кораблей (`BBBAh–BCC7h`)

Доказано чтением кода (случайное число — `B799h`):

- одиночный охотник (ветвь `BC46h`): число 0–63; 0 → Thargoid (15), 1–11 → Fer-de-Lance (14), 12–29 → Asp (13),
  30–45 → Cobra (12), остальное → Python (11); созданный корабль враждебен всегда, если это таргоид, иначе —
  с вероятностью 51 из 256;
- мирные и полиция (ветвь `BC7Fh`): по трём битам числа — торговец Cobra (9) или Python (10), либо тип 7 или
  Viper (8);
- стая (`BCABh`): от 2 до 4 кораблей типов 16 и 17 — Sidewinder и Krait вперемешку;
- при миссии 3 в системе-цели (состояние 4) вместо обычного выбора выходит тип 15 — таргоиды; при состоянии 1 —
  тип 10.

Чем выбирается ветвь (правление системы `D09Dh`, груз в трюме `D06Eh`, `D071h`, `D075h` — рабы, наркотики, оружие
участвуют в расчёте) — разобрано не до конца.

## Миссии: как на самом деле

### Выдача (`DDF7h–DE95h`, выполняется при прибытии после прыжка)

1. Если номер галактики `D065h` равен нулю — миссий нет: **в первой галактике миссии не выдаются.**
2. Счётчик прибытий `D063h` увеличивается на 1; дальше смотрится его **младший байт** и флаги `D0B0h`:
   - бит 0 сброшен и младший байт ≥ 20h (32) → выдаётся миссия 1 «Сверхновая»;
   - иначе бит 1 сброшен и младший байт ≥ 80h (128) → миссия 2 «Скрывающее устройство»;
   - иначе бит 2 сброшен и младший байт ≥ FEh (254) → миссия 3 «Захват станции».

Это в точности то, что записано в комментариях Elite Legend («счётчик прыжков… выдать 1-ю, 2-ю, 3-ю миссию»):
Legend унаследовал условия ZX 48K. Миссии идут строго по порядку, каждая один раз.

### Миссия 1, «Сверхновая»

- Выдача: бит 0, `D081h` = 1, сообщение (слово 2 очереди), утечка топлива (`DE97h`: топливо в ноль, «FUEL LEAK»).
- На станции (запись 0 таблицы переходов, `E6AEh`): вопрос «WILL YOU SAVE US (Y/N)?»; при ответе Y — груз
  обнуляется (17 товаров и счётчик), ставится бит 5 (беженцы на борту) и `D084h` (большой трюм).
- Пока `D081h` не ноль, любой прыжок выполняется как галактический (`DC8Eh` → `DC4Eh`): номер галактики + 1,
  семена сдвигаются, правовой статус обнуляется, `D081h` и состояние миссии 3 сбрасываются, галактический привод
  тратится.
- Награда (запись 1, `E8AEh`, на станции, когда `D081h` = 0 и бит 5 стоит): бит 5 сбрасывается, старший байт счёта
  побед + 1 (то есть +256 побед), 100 единиц камней (`D07Ah` = 64h), трюм занят (`D07Ch` = 23h), экран с
  благодарностью.

### Миссия 2, «Скрывающее устройство»

- Выдача: только бит 1; никакого сообщения.
- В полёте (`BBC9h`): если бит 1 стоит, а бита 6 (устройство получено) нет, Asp ещё не выходил в этой системе
  (`9CB2h`) и случайное число меньше 1Eh (30 из 256) — появляется Asp (тип 13), враждебный.
- Подбор контейнера (`D190h` с кодом FFh → `D183h`): бит 6, +256 побед, сообщение «CLOAKING DEVICE». На экране
  статуса устройство показывается строкой.

### Миссия 3, «Захват станции»

Состояние `D0AFh`: 1 — выдана (после прыжка), 2 — после следующего прибытия; при стыковке в состоянии 1 или 2
(`7278h` → `D123h`) — предложение «WANTED BY GALCOP… (Y/N)?»: N — состояние 0, Y — состояние 3 и бит 7 (выдана
глушилка ECM). При каждом прибытии текущая система сверяется с целью (`DE18h`, `EF37h`): совпала — состояние 4.
В состоянии 4 станция враждебна (`9CC2h`), вместо обычных кораблей выходят таргоиды (`BC25h`), вражеский ECM
без глушилки действует иначе (`B7F4h`). Уничтожение станции в состоянии 4 (`A510h`) ставит в `D0AFh` бит 3.
Состояние 5 при стыковке (`D14Dh`) — награда: +256 побед, бит 3 в `D0B0h`, экран с поздравлением, состояние 0.
Как именно состояние «станция уничтожена» переходит в 5 и как выбирается система-цель — не разобрано.

### Чем наша реализация (T47) отличается от ZX 48K

| | ZX 48K | Вектор сейчас |
|---|---|---|
| когда выдаются | по счётчику прибытий: 32-е, 128-е, 254-е (младший байт) | по одной на каждые 256 побед |
| первая галактика | миссий нет | выдаются |
| награда за «Сверхновую» | 100 камней и +256 побед | 100 камней |
| награда за скрывающее устройство | устройство и +256 побед | устройство |
| награда за «Захват станции» | +256 побед | только текст |
| большой трюм при спасении беженцев | ставится | нет |
| прыжок при сверхновой | любой прыжок — галактический | так же |
| Asp с устройством | 30 из 256 при появлении корабля | 1 из 8 вместо охотника |

## Прочее установленное

- **Сохранение** — на ленту подпрограммами ПЗУ; в текстах есть «SECURITY NUMBER» (защита Lenslok).
- **Стыковочный компьютер** — мгновенная стыковка с показом (`7199h`), см. `zx48_texts.md`.
- **Утечка топлива** при уроне — 1 случай из 64 (`D1E9h`), там же.
- **Галактический прыжок** обнуляет правовой статус (`DC7Bh`).
- **Контрабанда**: покупка рабов и наркотиков добавляет к правовому статусу по 4 за единицу, оружия — по 2 (`D1ADh`).
