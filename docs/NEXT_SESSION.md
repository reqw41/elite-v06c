# Старт новой сессии (состояние на 07.10.2026)

## Что это

Elite для ванильного Вектора-06Ц: i8080, 48 КБ под программу + две плоскости экрана (4 цвета), звук ВИ53.
Основа — кассетная версия BBC Micro (6502, 22 КБ). Игра пишется заново на i8080 и сверяется с настоящим кодом
BBC, исполняемым под Node.

## Прочитать сначала

1. `docs/PORT_PLAN.md` — план, этапы P0–P7, §7 решения владельца.
2. `docs/spec/oracle.md` — эталон: что доказано, расписание кадров, вызов одной процедуры.
3. `docs/tasks/README.md` — доска.
4. `docs/CONTRACTS.md` — правила.

## Решения владельца (не пересматривать)

- Без квазидиска; Elite Legend (ZX128) в основу не идёт, он донор текстов, моделей и миссий.
- Основа — кассета BBC, потом расширения (§5 плана).
- Экран как на BBC: обзор 256×192 двухцветный точка в точку, панель четырёхцветная, точки двойной ширины.
- Версия Acorn Electron — справочная, если не хватит скорости.
- Отдельной модели на JS нет; этапа «сначала Z80» нет — код сразу для i8080.
- Обзор белый, рамки панели тоже белые (палитра одна на весь экран); панель — красный, белый, зелёный.
- Шрифт — свой тонкий 5×7 (`v06c/data/font.bin`).
- Клавиши: F1–F5 — f0–f4 BBC, **СС + F1–F5 — f5–f9** (ближняя карта, данные о системе, цены, статус, груз).
  Раскладка — `tools/convert/keys.py`.
- Скорость: сначала М1 на точной арифметике и профиль, потом приближённая арифметика (логарифмы, как в версии для
  второго процессора) отдельной быстрой сборкой. Приближённая арифметика будет — это решено.
- Горячий код пишется под i8080 «по смыслу», а не по командам 6502: смысл процедуры — короткой функцией на JS,
  сверенной с 6502 в эталоне; код i8080 — под этот смысл; парный тест — по-прежнему против 6502. Порядок: T07 →
  М1 и профиль → трассировка в эталоне, кто читает побочные записи (`T`, `T1`, `U`, `P`) → переписать горячее.
  Холодный код переносится как есть. Модели всей игры на JS нет.
