# Старт новой сессии (состояние на 07.10.2026)

## Что это

Elite для ванильного Вектора-06Ц: i8080, 48 КБ под программу + две плоскости экрана (4 цвета), звук ВИ53.
Основа — кассетная версия BBC Micro (6502, 22 КБ). Игра пишется заново на i8080 и сверяется с настоящим кодом
BBC, исполняемым под Node.

## Прочитать сначала

1. `docs/PORT_PLAN.md` — план, этапы P0–P7, §7 решения владельца.
2. `docs/spec/oracle.md` — эталон: что доказано, расписание кадров, вызов одной процедуры.
3. `docs/tasks/README.md` — доска.
4. `docs/CONTRACTS.md` — правила.

## Решения владельца (не пересматривать)

- Без квазидиска; Elite Legend (ZX128) в основу не идёт, он донор текстов, моделей и миссий.
- Основа — кассета BBC, потом расширения (§5 плана).
- Экран как на BBC: обзор 256×192 двухцветный точка в точку, панель четырёхцветная, точки двойной ширины.
- Версия Acorn Electron — справочная, если не хватит скорости.
- Отдельной модели на JS нет; этапа «сначала Z80» нет — код сразу для i8080.
- Обзор белый, рамки панели тоже белые (палитра одна на весь экран); панель — красный, белый, зелёный.
- Шрифт — свой тонкий 5×7 (`v06c/data/font.bin`).

## Сделано

- T01, T02: эталон `tools/oracle/` (ядро 6502, заглушки системы BBC). Сверен с jsbeeb на 425 проходах цикла:
  расходится только `LASCT`. Время по расписанию, вызов одной процедуры, сценарий `tests/golden/launch.json`.
- Q1–Q3 (локальная модель): `v06c/data/ships.asm`, `python.asm`, `words.asm`, `dials.bin` — побайтно равны BBC.
- T04: каркас Вектора — `v06c/src` (`elite.asm`, `sys.asm`, `text.asm`, `dash.asm`, `demo.asm`), сборка
  `v06c/build.sh`, карта памяти `docs/spec/v06c-memory.md` (рабочие области = адрес BBC + `B000h`), стенд
  `v06c/tools/v06c.mjs` (кадры, вызов одной процедуры, снимок). `TT26` сверен с эталоном.
- T05: `PIXEL`, `LOIN`, `HLOIN` (`v06c/src/line.asm`) — экран равен эталону на 12 000 случаях.
- T06: арифметика, 20 процедур (`v06c/src/arith.asm`), стенд парных тестов `v06c/tools/pair.mjs`, правила
  переноса `docs/spec/porting.md`. Рост кода ×1,35; **время в 1,6–3,3 раза больше BBC** — см. отчёт T06.

Проверить, что всё живо:

```sh
node tools/oracle/scenario.js launch          # «совпало, 525 проходов»
node tools/oracle/xcheck.mjs launch           # 425 шагов, 82 с различиями (только LASCT)
for t in ships words dials; do python3 -I tools/convert/test_convert.py $t; done
sh v06c/build.sh && for t in t04 t05 t06; do node v06c/test/$t.mjs | tail -1; done   # три «всё совпало»
node v06c/tools/shot.mjs                      # снимок кадра в work/v06c/elite.png
```
