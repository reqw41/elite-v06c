# Эталон: кассетная версия BBC Elite под Node

`tools/oracle/` — настоящий код игры в голом ядре 6502. Модели игры на JS нет: поведение порта сверяется с этим
стендом.

| файл | что |
|---|---|
| `cpu6502.js` | ядро 6502: документированные команды, счёт тактов; десятичного режима нет (игра его не использует) |
| `bbc.js` | машина: образ памяти из `orig/bbc/cassette/3-assembled-output`, VIA (кадр, таймер, клавиши), видеосхема, OSBYTE, OSWORD 7 (журнал звуков), снимок экрана в PNG |
| `title.js` | запуск до заставки и экрана статуса, снимки в `work/oracle/`, проверка повторяемости |
| `jsbeeb_dump.mjs` | настоящий BBC (jsbeeb, `orig/tools/jsbeeb`) до входа в игру, память в файл |
| `xcheck.mjs` | сверка стенда с jsbeeb: оба идут по сценарию, память сравнивается на каждом проходе цикла |

Нужны (в git не входят): `orig/bbc/cassette`, `orig/bbc/mos/os120.rom` (ПЗУ системы — ради шрифта),
`orig/tools/jsbeeb` с `npm install --omit=dev --ignore-scripts` (только для сверки).

## Что доказано (07.10.2026)

- Код, модели, словарь и панель в образе стенда побайтно равны памяти настоящего BBC в точке входа TT170.
  Отличались только байт контрольной суммы перед моделями и вектор VEC.
- `node tools/oracle/xcheck.mjs launch`: 425 проходов цикла — заставка, вторая заставка, станция, взлёт, полёт,
  разгон, огонь с тангажом. Память 0–&7FFF (кроме стека и областей системы) равна jsbeeb на каждом проходе,
  включая экран, блоки кораблей и генератор случайных чисел. Единственное расхождение — `LASCT`, на 82 проходах.
- Два прогона `title.js` дают одинаковые хеши.

## Привязка ко времени

- **`LASCT`** (счётчик паузы лазера) уменьшается в обработчике кадра, а не в цикле. Его значение зависит от
  того, сколько кадров занял проход: в стенде и в jsbeeb оно расходится на ±1. Для сверки с Вектором число
  кадров на проход надо задавать расписанием, а не получать из скорости машины.
- Ожидание кадра (`WSCAN`, `DELAY`) на состояние в проверенном сценарии не влияет.
- Генератор случайных чисел игра не засевает: в `RAND` остаётся след загрузчика. В стенде стоит значение,
  снятое с jsbeeb: `C7 94 27 1D`.

## Синхронизация

Точка сверки — приход в метку: `TLL2` (цикл заставки), `MLOOP` (главный цикл на станции и в полёте).
Клавиши — внутренние номера BBC (N=&55, пробел=&62, f0=&20, A=&41), меняются в момент прихода в метку.

## Палитра

Обзор: 0 — чёрный, 1 — белый. Панель (логический цвет → цвет BBC): 0 — чёрный, 1 — красный, 2 — жёлтый,
3 — зелёный.

## Не сделано

OSWORD 0 (ввод имени), OSFILE (сохранение), джойстик (всегда в середине), расписание кадров, вызов отдельной
процедуры — задача T02.
