# Вектор: карта памяти, экран, палитра, клавиатура

Сделано в T04 (07.10.2026). Проверка: `sh v06c/build.sh && node v06c/test/t04.mjs`.

## Карта памяти

| адрес | что |
|---|---|
| `0038h` | `JP isr` — прерывание кадра (RST 7) |
| `0100h`…`rom_end` | образ `v06c/build/elite.rom`: код, шрифт, панель, позже модели и словарь |
| …`AFFFh` | свободно (сборка печатает, сколько осталось) |
| `B000h–BF3Fh` | **рабочие области: адрес BBC `&0000–&0F3F` + `WS` (`WS = B000h`)** |
| `BF40h–BFFFh` | свободно (192 Б) |
| `C000h–DFFFh` | плоскость обзора, бит 1 цвета |
| `E000h–FFFFh` | вторая плоскость, бит 0 цвета |

Плоскости `8000h` и `A000h` заняты программой и областями; палитра строится так, что их биты цвет не меняют.

### Рабочие области

Адрес ячейки на Векторе = адрес на BBC + `B000h`. Поэтому состояние сравнивается с эталоном побайтно, без
таблиц пересчёта, а старший байт адреса сразу называет область.

| BBC | Вектор | что | имя в `bbc_vars.inc` |
|---|---|---|---|
| `&0000–&00FF` | `B000h` | нулевая страница игры | `ZP`, `RAND`, `SC`, `XC`, `YC`, `INWK`, … |
| `&0100–&01FF` | `B100h` | куча `XX3` (на BBC — низ страницы стека) | `XX3` |
| `&0200–&02FF` | `B200h` | *на BBC — векторы системы.* Переменные слоя Вектора: кадры, клавиатура, палитра | `VARS` |
| `&0300–&0371` | `B300h` | пилот, звёздная пыль | `T_`, `TP`, `QQ0`, … `SVC` |
| `&0372–&03FF` | `B372h` | свободно (142 Б) | |
| `&0400–&08FF` | `B400h` | *на BBC — словарь `QQ18` и буферы системы.* Запас под таблицы, которые строятся при запуске (умножение); сверху — **стек**, растёт вниз от `B900h` | `STACK` |
| `&0900–&0D3F` | `B900h` | блоки кораблей снизу, куча отрезков сверху | `K_` |
| `&0D40–&0F33` | `BD40h` | слоты и переменные | `WP`, `FRIN`, `LASCT`, `LSO`, … `NOSTM` |

Словарь `QQ18` на Векторе лежит в образе (данные только для чтения), а не по адресу `B400h`.

`v06c/src/bbc_vars.inc` делает `tools/convert/bbcvars.py` из листинга BBC (209 меток). Правила имён:
`%` → `_` (`K%` → `K_`, `T%` → `T_`); имя, совпавшее с регистром, получает `_` в конце: `P` → `P_`, `R` → `R_`,
`de` → `de_`. В диапазон `&0900–&0D3F` попали ещё метки загрузчика BBC (`CHECKbyt` … `CHKb`) — в игре не нужны.

Что **не** совпадает с BBC побайтно и требует оговорки при сверке:

- ячейки-указатели (`SC`, `INF`, `XX0`, `SLSP`, `P+1`…): на Векторе в них адреса Вектора;
- рабочие ячейки процедур, которые на i8080 заменены регистрами (у каждой процедуры — в её заголовке);
- экран: у BBC строчная память `&6000–&7EFF`, у Вектора столбцовая — сравнивается через
  `v06c/tools/screen.mjs`.

### Стек

`B900h` вниз, в запас `B400h–B8FFh`. Обработчик кадра кладёт 10 байт. Глубину надо замерить, когда появится
главный цикл (P4), и тогда же решить, сколько из запаса отдать таблицам.

## Экран

Точка `(x, y)`, `y = 0` сверху: байт `плоскость + (x >> 3)·256 + (255 − y)`, бит `7 − (x & 7)`.
Порт прокрутки `03h = FFh`.

| строки | что | плоскости |
|---|---|---|
| 0–191 | обзор 256×192, как на BBC точка в точку | `C000h`; вторая плоскость пуста (цвет в обзоре — расширение R1) |
| 192–247 | панель 256×56: точки BBC двойной ширины, 4 цвета | бит 1 — `C000h`, бит 0 — `E000h` |
| 248–255 | пусто | |

Соответствие экрану BBC: байт обзора `&6000 + (y >> 3)·256 + (x >> 3)·8 + (y & 7)` ↔
`C000h + (x >> 3)·256 + 255 − y`, биты в байте идут одинаково.

## Палитра

Номер регистра палитры = `8·(бит 8000h) + 4·(бит A000h) + 2·(бит C000h) + (бит E000h)`. Регистр `i` получает
цвет `i & 3`, итого четыре цвета на весь экран. `pal_set` (HL → 4 байта `BBGGGRRR`) готовит 16 регистров,
прерывание кадра записывает их в гашении.

| цвет | плоскости | панель BBC | сейчас (`pal_flight`) | вариант `-DVIEW_YELLOW` |
|---|---|---|---|---|
| 0 | — | чёрный | `00` чёрный | `00` |
| 1 | `E000h` | красный | `07` красный | `07` |
| 2 | `C000h` — **обзор** | жёлтый | `FF` белый | `3F` жёлтый |
| 3 | обе | зелёный | `38` зелёный | `38` |

**Открытый вопрос владельцу.** На BBC экран разделён на два режима со своими палитрами: обзор белый, панель —
красный, жёлтый, зелёный. На Векторе палитра одна, а обзор рисуется в одной плоскости, поэтому цвет обзора
совпадает с цветом 2 панели. Либо обзор белый и рамки панели белые (сейчас), либо панель как на BBC и обзор
жёлтый. Меняется одним байтом таблицы.

## Прерывание кадра

`isr` (`v06c/src/sys.asm`): опрос клавиатуры → запись палитры, если просили → `v_frames + 1` → `DL = 30`,
`LASCT − 1`, если не ноль (это всё, что обработчик кадра BBC делает с состоянием игры). В сборке `-DSCHED`
последний шаг убран: кадры считает стенд на границе прохода, как эталон (`docs/spec/oracle.md`).

## Клавиатура

Матрица читается в прерывании (порт B ВВ55 на вводе виден машине как бордюр и режим 512 — поэтому только в
гашении кадра). `kb_rows[0..7]`, 1 — нажата; `kb_mod`: бит 5 — СС, 6 — УС, 7 — РУС/ЛАТ.
`kb_test`: A = строка·8 + бит → NZ, если нажата.

```
стр │ бит 7   6   5   4   3   2   1   0
 7  │ ПРОБ  ^   ]   \   [   Z   Y   X
 6  │  W    V   U   T   S   R   Q   P
 5  │  O    N   M   L   K   J   I   H
 4  │  G    F   E   D   C   B   A   @
 3  │  /    .   =   ,   ;   :   9   8
 2  │  7    6   5   4   3   2   1   0
 1  │ F5   F4  F3  F2  F1  АР2 СТР  ↖
 0  │  ↓    →   ↑   ←  ЗБ  ВК  ПС  ТАБ
```

Клавиши игры на клавиши Вектора не разложены — это P4 (на BBC десять функциональных клавиш, на Векторе пять).

## Шрифт

`v06c/data/font.bin` — свой, тонкий 5×7 в знакоместе 8×8, знаки 32–127 (`tools/convert/font.py`, лист —
`v06c/data/font.png`). Формат тот же, что у шрифта в ПЗУ BBC, поэтому для сверки текста эталону подставляется
этот же файл по адресу `&C000`. Со шрифтом ПЗУ BBC побайтно совпадает один знак — пробел
(`python3 -I tools/convert/font.py --cmp`).
