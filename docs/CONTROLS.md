# Управление (обычный образ `elite.rom`)

В полёте клавиши — под русскую клавиатуру Вектора-06Ц (решение владельца 17.10.2026): по первой букве действия.
Перевод делает прерывание кадра (`fly_keys` в `v06c/src/sys.asm`, таблицы — `tools/convert/keys.py`), игра
по-прежнему видит клавиши BBC. В полёте старые клавиши BBC, чьё действие переехало, не действуют. На паузе, на
картах, в доке и при вводе имени — раскладка BBC. Образ стенда (`elite_t.rom`) — как на BBC.

## Полёт

| действие | клавиша Вектора | у BBC |
|---|---|---|
| крен влево / вправо | ← → | `<` `>` |
| нос вниз / вверх | ↑ ↓ | S X |
| огонь | Пробел | A |
| разгон / тормоз | Я / ТАБ | Пробел / `?` |
| ракета: цель / пуск / снять | Ц / Р / С | T / M / U |
| ЕСМ | Е | E |
| энергетическая бомба | Б | TAB |
| спасательная капсула | К | ESCAPE |
| автопилот стыковки: включить / отключить | А / О | C / P (диск) |
| прыжок к планете | П | J |
| гиперпрыжок / галактический | Г / УС + Г | H / CTRL + H |
| маскировка (после миссии) | М | Y |
| вид вперёд, назад, влево, вправо | F1–F4 | f0–f3 |
| пауза | СТР | COPY |

Джойстик в полёте: крен и тангаж, огонь — лазер, вторая кнопка — разгон.

## Экраны

F1–F5 — f0–f4 BBC (в доке: вылет, купить, продать, оборудование, галактическая карта), СС + F1–F5 — f5–f9
(ближняя карта, данные о системе, цены, статус, груз). На картах — стрелки; D, F, O — как у BBC.

## Пауза (СТР)

Раскладка BBC: ЗБ — дальше, АР2 — начать заново, Q / S — звук выкл. / вкл., A, X, F, Y, J, K — настройки BBC.
