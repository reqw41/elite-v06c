# Общие правила для исполнителей (elite-v06c)

1. Рабочая папка — только `~/projects/elite-v06c`. Временное — в `work/<задача>/` (в git не входит), не в /tmp.
2. `orig/` не менять и в git не добавлять: там чужой код (BBC Elite © Acornsoft, комментарии © Mark Moxon;
   Elite Legend © LoneWolf).
3. Эталон — код кассетной версии BBC (`orig/bbc/cassette`), исполняемый в `tools/oracle`. Поведение порта
   сверяется с ним, а не с чтением исходника и не «на глаз». Адреса меток — из
   `orig/bbc/cassette/3-assembled-output/compile.txt`.
4. Каждая процедура на i8080 сдаётся с парным тестом против своей процедуры на 6502. Раскладка переменных внутри
   рабочих областей — как на BBC (`docs/spec/v06c-memory.md`).
5. Образ проходит `tools/check_i8080.py`: ни одной команды Z80.
6. Никаких клавиш и кликов в окна хоста (osascript, CGEvent, activate). Эмуляторы — только без окна. Чужие
   процессы не убивать.
7. Числа в отчётах — только из вывода скриптов; скрипт кладётся в репозиторий.
8. В отчёте раздельно: «Доказано» (со ссылкой на файл, метку, скрипт) и «Гипотезы».
9. Git: коммитить только свои файлы; stash, checkout, reset чужого не делать. Одна задача — один исполнитель,
   отчёт — `docs/tasks/Txx-report.md`.
10. Исходники Legend (донор) — в cp866 с CRLF: читать через `LC_ALL=C iconv -f cp866 -t utf-8`.
