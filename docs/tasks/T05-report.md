# T05. Точка, отрезок, горизонтальная линия — отчёт (07.10.2026, архитектор)

Код — `v06c/src/line.asm`: `PIXEL`, `LOIN`, `HLOIN`. Проверка: `sh v06c/build.sh && node v06c/test/t05.mjs`.

## Доказано

Каждая процедура вызвана на Векторе и в эталоне с одним входом; после каждого вызова сравнивается весь обзор
(6144 байта) и ячейки концов `X1, Y1, X2, Y2`. Между очистками экрана 200 вызовов накладываются друг на друга —
проверяется исключающее ИЛИ.

| процедура | случаев | итог |
|---|---|---|
| `LOIN` | 4000: случайные, вертикали, горизонтали, диагонали, короткие (до 8 точек), края экрана, точки | совпало |
| `HLOIN` | 4000: случайные, до края экрана, `X1 = X2` | совпало |
| `PIXEL` | 4000: `ZZ` = 0, 79, 80, 143, 144, 255 и случайные | совпало |

Замер (вывод теста; BBC — 6502 при 2 МГц, Вектор — i8080 при 3 МГц, команда кратна четырём тактам):

| процедура | 6502, тактов | i8080, тактов | время Вектор / BBC |
|---|---|---|---|
| `LOIN`, в среднем 74 точки | 3387 | 8734 | 1,72 |
| `LOIN` пологий 200 точек | 8876 (4,44 мс) | 22 868 (7,62 мс) | 1,72 |
| `LOIN` крутой 150 точек | 6348 (3,17 мс) | 15 332 (5,11 мс) | 1,61 |
| `HLOIN`, в среднем 89 точек | 371 | 936 | 1,68 |
| `PIXEL` | 78 | 230 | 1,98 |

Размер кода без таблиц масок: `PIXEL` 67 → 62, `LOIN` 381 → 233, `HLOIN` 134 → 100; всего 582 → 395 байт (×0,68).
Столбцовый экран здесь выгоден: шаг по y — одна команда, две пары циклов BBC (вверх и вниз, вправо и влево)
заменены одним циклом с подменой команды.

## Решения

- Концы в `X1..Y2` переставляются так же, как на BBC (ими пользуются вызывающие). Рабочие ячейки `P, Q, R, S,
  SWAP, T, T1, YSAV, SC, SCH` не воспроизводятся — их заменяют регистры. При сверке состояния игры (P4) эти
  ячейки надо исключать: готовые хеши `tests/golden` покрывают нулевую страницу целиком и для этого не годятся,
  стенду понадобится выгрузка байтов с маской.
- Регистры: A — как на BBC, X → B, Y → C; BC сохраняется.

## Гипотезы

- Отрезок на Векторе в 1,6–1,7 раза медленнее BBC. Запас есть: цикл пологого отрезка стоит 112 тактов на точку,
  развёртка по восьми положениям маски (без сдвига маски) по счёту команд даёт около 76; деление наклона
  (восемь шагов, около 700 тактов на отрезок) — заметная доля коротких отрезков. Делать после замера на М1.
