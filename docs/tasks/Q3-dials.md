# Q3. Картинка панели BBC → две плоскости Вектора

Менять и создавать можно только: `tools/convert/dials.py`, `v06c/data/dials.bin`, `v06c/data/dials.png`.

## Что есть

`/Users/boris/projects/elite-v06c/orig/bbc/cassette/1-source-files/images/P.DIALS.bin` — 1792 байта, панель
приборов: 128 точек в ширину, 56 строк, 4 цвета.

Раскладка BBC:
- 7 рядов знакомест, в каждом ряду 32 знакоместа, в знакоместе 8 байт (строки сверху вниз);
- байт для ряда `r` (0–6), знакоместа `cx` (0–31), строки `l` (0–7) лежит по смещению `r*256 + cx*8 + l`;
- в байте 4 точки, слева направо `k` = 0, 1, 2, 3; цвет точки `k`:
  `c = ((байт >> (7-k)) & 1) * 2 + ((байт >> (3-k)) & 1)`;
- точка имеет координаты `X = cx*4 + k` (0–127), `y = r*8 + l` (0–55).

## Что сделать

Написать `tools/convert/dials.py` (Python 3, только стандартная библиотека). Он пишет:

1. `v06c/data/dials.bin`, 3584 байта: сначала плоскость 0 (1792 байта), затем плоскость 1 (1792 байта).
   - Каждая точка BBC занимает на Векторе две точки рядом: `x = 2*X` и `x = 2*X + 1` (ширина 256).
   - В плоскости 0 бит точки равен `c & 1`, в плоскости 1 — `c >> 1`.
   - Порядок байтов в плоскости: по столбцам. Столбец `col` = `x // 8` (0–31), в столбце 56 байт сверху вниз.
     Смещение байта: `col*56 + y`. Старший бит байта — левая точка: бит номер `7 - (x % 8)`.
2. `v06c/data/dials.png`, 512×112 точек (каждая точка Вектора — квадрат 2×2), цвета: 0 — чёрный (0,0,0),
   1 — красный (255,0,0), 2 — жёлтый (255,255,0), 3 — зелёный (0,255,0). PNG писать через `zlib` и `struct`,
   без сторонних библиотек.
