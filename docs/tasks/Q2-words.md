# Q2. Словарь текста BBC → исходник для sjasmplus

Менять и создавать можно только: `tools/convert/words.py`, `v06c/data/words.asm`.

## Что есть

`/Users/boris/projects/elite-v06c/orig/bbc/cassette/3-assembled-output/WORDS9.bin` — 1023 байта, словарь игры.
Записи идут подряд, номер записи — её порядковый номер с нуля. **Запись заканчивается байтом 0x00** (он не
зашифрован). Остальные байты зашифрованы: настоящий код = байт XOR 35.

Настоящие коды внутри записи:
- 32–95 — обычный знак ASCII;
- всё остальное — служебные коды (ссылки на другие записи и пары букв), их не расшифровывать.

## Что сделать

Написать `tools/convert/words.py` (Python 3, только стандартная библиотека). Он читает файл и пишет
`v06c/data/words.asm`:

- первая строка: `; создано tools/convert/words.py, руками не править`;
- метка `QQ18:`;
- на каждую запись — одна строка `db` с её байтами **как в файле** (зашифрованными), в виде `0x12`, включая
  завершающий байт 0x00;
- в конце той же строки комментарий: `; N: текст`, где N — номер записи, а текст — расшифровка: обычные знаки
  как есть, служебный код — в виде `<число>`;
- если после последнего завершающего байта остались байты — вывести их отдельной строкой `db`.

## Проверка (должна стать зелёной)

```sh
python3 -I tools/convert/words.py
python3 -I tools/convert/test_convert.py words
```

Ожидается строка «совпало, 1023 байт». Файл `tools/convert/test_convert.py` не менять.
