# T10. Рубеж М1: вращение корабля на заставке — отчёт (07.10.2026, архитектор)

Код: `v06c/src/title.asm` — `title_pass` (тело цикла `TLL2` из `TITLE`) и `title_demo` (свой запуск корабля для
образа). Проверка: `sh v06c/build.sh && node v06c/test/t10.mjs`. Вывод целиком —
`docs/research/profile_title_v06c.txt`.

## Доказано

Эталон и Вектор идут по циклу заставки проход за проходом; после каждого прохода равны: обзор (6144 байта),
панель, блок корабля, список отрезков, куча вершин `XX3`, рабочие области (нулевая страница, T%, K%, WP).

| заставка | корабль | проходов | итог |
|---|---|---|---|
| первая («Load New Commander») | Кобра Mk III, от точки вдали до полного размера | 300 | совпало |
| вторая («Press Fire or Space») | тип 3 | 150 | совпало |

Вне сравнения: рабочие ячейки `LOIN` и `SCAN` (`P, Q, R, S, SWAP, YSAV, SC, SCH, X1`) и указатели
(`V, XX0, XX19, INF`, указатель списка в блоке корабля) — в них адреса своей машины.

Образ `v06c/build/elite.rom` сам показывает вращающуюся Кобру (после нажатия любой клавиши):
`node v06c/tools/shot.mjs elite 40 work/v06c/t10-rom.png 1500`.

### Профиль Вектора (доля тактов по процедуре, в которой стоит команда; 450 проходов)

| доля | процедура | что это |

| 23,6 % | `LOIN` | циклы отрезка: каждый отрезок печатается дважды — стереть и нарисовать |

| 6,4 % | `LL31` | деление (проекция вершины, два на вершину) |
| 6,1 % | `li_div` | деление наклона в `LOIN` |
| 4,0 % | `FMLTU` | обёртка умножения |

| 2,7 % | `MVS5` | вращение корабля |

Рядом — профиль эталона: `docs/research/profile_title_bbc.txt`.

## Что из этого следует

- Отрезок с делением наклона и печатью списка — 37 % прохода (`LOIN` + `LL155` + `li_div`); поворот вершин
  (`LL51` + `mul8` + `FMLTU` + `LL38`) — 27 %; обвязка `LL9` — 17 %; деления — 12,5 % (`LL31` + `li_div`).
- Логарифмы затронут только деления и часть умножений: потолок выигрыша от них — около 12–15 % прохода.
  Больше даёт переписывание по смыслу: `LL51` в регистрах, `LL9` без пересылок через ячейки, развёрнутый цикл
  отрезка, печать списка без копирования.
- Опрос клавиш, съедающий на BBC 12 % прохода заставки, на Векторе бесплатный (матрица снята в прерывании).

## Не сделано

- Подготовка заставки (`RESET`, `TT66`, `NWSHP`, `CLYNS`, текст из словаря `TT27`) не перенесена: тест копирует
  состояние эталона в начале каждой заставки. Перенос — этапы P4, P5.
- Выход из цикла по клавише (`RDKEY`) — нет; образ крутит корабль бесконечно.
- На MiSTer не запускалось.
