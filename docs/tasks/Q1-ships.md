# Q1. Модели кораблей BBC → исходник для sjasmplus

Менять и создавать можно только: `tools/convert/ships.py`, `v06c/data/ships.asm`, `v06c/data/python.asm`.

## Что есть

- `/Users/boris/projects/elite-v06c/orig/bbc/cassette/3-assembled-output/SHIPS.bin` — 2502 байта, на BBC лежит с
  адреса 0x563A.
  - Первые 26 байт — таблица из 13 адресов моделей (слова, младший байт первым).
  - Один из адресов равен 0x7F00 — это модель Python, она лежит отдельно.
  - Остальные адреса указывают внутрь этого же файла (адрес − 0x563A = смещение). Адреса могут повторяться.
  - После таблицы до конца файла идут сами модели, подряд.
- `/Users/boris/projects/elite-v06c/orig/bbc/cassette/3-assembled-output/PYTHON.bin` — 256 байт, адрес 0x7F00.

## Что сделать

Написать `tools/convert/ships.py` (Python 3, только стандартная библиотека). Он читает два файла выше и пишет:

1. `v06c/data/ships.asm`:
   - метка `XX21:` и 13 строк `dw <метка>`: для адреса 0x7F00 — `ship_python`, для остальных — `ship_XXXX`, где
     XXXX — адрес на BBC в шестнадцатеричном виде (например `ship_5654`);
   - затем байты от конца таблицы до конца файла строками `db` по 16 байт, в виде `0x12`;
   - перед байтом, с которого начинается модель, — строка с её меткой `ship_XXXX:` (каждая метка один раз);
   - метку `ship_python` в этом файле не определять.
2. `v06c/data/python.asm`: метка `ship_python:` и все 256 байт строками `db` по 16.

В начале каждого файла — комментарий `; создано tools/convert/ships.py, руками не править`.

## Проверка (должна стать зелёной)

```sh
python3 -I tools/convert/ships.py
python3 -I tools/convert/test_convert.py ships
```

Ожидается две строки «совпало». Файл `tools/convert/test_convert.py` не менять.
