## Сначала прочитать

1. `docs/spec/porting.md` — правила переноса и ловушки (перенос при вычитании обратный!).
2. `v06c/src/arith.asm` — образец: `MULT1`, `MAD`, `ADD`, `DVID4`, `LL28` уже перенесены, их надо **вызывать**,

Регистры: A = A, X → B, Y → C, перенос = перенос. Ячейки (`Q`, `S`, `R_`, `T`, `T1`, `K`, `XX`, `ALP1`,
`DELTA`, `SZ`) уже объявлены в `v06c/src/bbc_vars.inc`. Обратите внимание: ячейка `R` на Векторе зовётся `R_`,
ячейка `P` — `P_`.

## Что перенести (текст BBC)

```
.MU5                    \ K(3 2 1 0) = (A A A A), перенос 0
 STA K
 STA K+1
 STA K+2
 STA K+3
 CLC
 RTS

.TIS1                   \ A = (-X * A + (S R)) / 96
 STX Q
 EOR #%10000000
 JSR MAD
                        \ дальше исполнение проваливается в DVID96
.DVID96                 \ A = A / 96, знак — бит 7
 TAX
 AND #%10000000
 STA T
 TXA
 AND #%01111111
 LDX #254
 STX T1
.DVL3
 ASL A
 CMP #96
 BCC DV4
 SBC #96
.DV4
 ROL T1
 BCS DVL3
 LDA T1
 ORA T
 RTS

.MUT3                   \ на BBC запись в P здесь лишняя, но её надо сделать
 LDX ALP1
 STX P
.MUT2
 LDX XX+1
 STX S
.MUT1
 LDX XX
 STX R
                        \ дальше исполнение проваливается в MULT1 (на Векторе: jp MULT1)

.DV42
 LDA SZ,Y
.DV41
 STA Q
 LDA DELTA
                        \ дальше исполнение проваливается в DVID4 (на Векторе: jp DVID4)
```

Подсказки.

- `DVID96`: в цикле `CMP #96 : BCC DV4 : SBC #96` перед `ROL T1` перенос на 6502 равен 1, если вычитали, и 0,
  если нет. На i8080 после `cp 96` CY = 1 значит «меньше» — наоборот. В `T1` должны попасть биты 6502.
  На выходе: A = `T1 | T`, X = 254, перенос 0, в `T` — знак, в `T1` — частное.
- В `DV42` Y — индекс в таблице `SZ`; Y (регистр C) менять нельзя.
- `TIS1`: `JSR MAD` → `call MAD`; после него A уже готов для `DVID96`.
